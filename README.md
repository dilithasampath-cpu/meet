## Netlify හි සකස් කරන ආකාරය

1. මේ ෆෝල්ඩරය GitHub repository එකකට උඩුගත කරන්න (private repository එකක් වුවත් හරි).
2. Netlify → Add new site → Import an existing project → GitHub repository එක තෝරන්න.
   Build settings නොවෙනස්ව තබන්න (netlify.toml මගින් ඉබේම සකසයි).
3. Site configuration → Environment variables වල මේවා එකතු කරන්න:
   * `JUDGE_PIN` = විනිසුරුවන්ට දෙන රහස් අංකය
   * `ADMIN_PIN` = ඇඩ්මින්ට පමණක් රහස් අංකය (JUDGE_PIN එකට වඩා වෙනස් විය යුතුයි)
   * (අවශ්‍ය නම් පමණක්) `JUDGES_CAN_EDIT` = `true` - දුන් විට විනිසුරුවන්ටත් සුරැකූ ප්‍රතිඵල නැවත වෙනස් කළ හැකියි.
4. Deploys → Trigger deploy → Deploy site (PIN දැමූ පසු නැවත deploy කළ යුතුයි).
5. සියලු දෙනාම එකම සබැඳිය පාවිච්චි කරයි: `https://ඔබේ-අඩවිය.netlify.app/`
   (ඇඩ්මින් PIN එකෙන් පිවිසුණොත් ඇඩ්මින් මෙවලම් පෙනේ.)
